# Q20i desktop screen concepts

These four static images explore the `design-thoughts.md` direction with **Soundcore Q20i (A3004)** selected.

| Image | Screen |
| --- | --- |
| `01-overview-q20i.png` | Device overview and ambient sound modes |
| `02-equalizer-q20i.png` | 10-band equalizer editor |
| `03-quick-presets-q20i.png` | Locally saved EQ presets for this model |
| `04-device-information-q20i.png` | Device details and supported features |

`q20i-official-product.png` is the Q20i product render sourced from the [official Soundcore product page](https://www.soundcore.com/products/q20i-a3004z31). It is included as a model-specific visual reference; confirm its usage rights before shipping it in the app.

The UI images are design concepts, not live screenshots. Battery, connection, firmware, serial number, and EQ state are illustrative sample values. The Q20i implementation currently exposes ambient sound modes, a 10-band EQ, battery, serial number, and firmware information. It does not expose custom button mapping, so that inspiration screen is represented by the supported device information view instead.

For eventual coverage of all supported headsets, maintain a separate model-keyed image for each model. Until a matching image is available for a model, show a neutral fallback icon and the model name rather than another headset's product image.
